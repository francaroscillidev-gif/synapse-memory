# 🌐 Synapse Browser Extension (Manifest V3)

Capture snippets, code, documentation, and web articles straight from Chrome, Brave, or Edge into your local **Synapse Memory** AI engine.

## 🚀 How to Install in 10 Seconds:
1. Open your browser and navigate to:
   - Chrome: `chrome://extensions`
   - Brave: `brave://extensions`
   - Edge: `edge://extensions`
2. Enable **Developer Mode** (toggle in the top-right corner).
3. Click **"Load unpacked"** (or "Carica estensione non compattata").
4. Select this `extension` folder.
5. Make sure `synapse ui` is running in your terminal (`http://127.0.0.1:8484`).

## 💡 Features:
* **Right-Click Context Menu:** Highlight any text on any page -> Right-click -> Select **"🧠 Save to Synapse Memory"**.
* **Popup Quick Note:** Click the extension icon to verify server connection and jot down quick notes.
